# 资讯原创剪辑版执行计划

目标不是把来源文章或视频换皮后重发，而是建立“多来源检索 → 证据化选题 → 原创图文/脚本 → 合法素材合成 → 人工复核 → 多账号分发”的可审计流水线。

## 阶段 1：Android 内容包 MVP（当前已完成）

- 用户配置主题、标签、48 小时等回看窗口和最多来源数。
- 从最多 10 个 HTTPS RSS/Atom 信源读取标题、摘要、链接和时间。
- URL 去重，过滤过期和完全不相关的条目，按主题相关度与发布时间排序。
- 调用用户选择的 OpenAI 兼容模型接口。
- 生成标题、带来源图文稿、60–120 秒口播稿、封面提示词、6–12 个分镜和标签。
- 保存结构化 JSON 内容包，允许在手机上编辑和复制。
- 发布前必须人工核查，不自动点击最终发布。

验收：空信源、无相关资讯、无 Key、模型限流和非法 JSON 都给出可理解的错误；内容包保留所用来源；单元测试和 Debug 构建通过。

## 阶段 2：在线检索与证据层

- 新建服务端任务 API、队列和定时调度；Android 变为控制台和人工审核端。
- 接入可配置的正规搜索 API、RSS 和站点官方 API，不直接把搜索结果页当事实来源。
- 保存来源标题、URL、发布时间、抓取时间、摘要哈希和授权/引用说明。
- 先让模型提取“事实主张—对应来源”，再生成内容；数字、直接引语和争议信息必须能回指来源。
- 同一事件聚类去重；多来源冲突时标记“待核实”，阻止自动进入发布队列。
- 加入成本预算、缓存、速率限制、失败重试和供应商切换。

验收：每个关键事实至少有一个可访问来源；热点重复任务不会重复付费生成；任何来源冲突都会进入人工复核。

## 阶段 3：素材与视频合成

- 分镜只能引用自有素材、明确授权素材、公共领域素材、可商用素材库或合规 AI 生成画面。
- 为每个素材保存来源、许可、作者、下载时间和使用范围。
- 按模板生成 9:16 画面、旁白、字幕、转场、片头片尾和封面。
- TTS、图片和视频生成供应商均通过适配器接入，Key 存在服务端密钥库，不下发到客户端。
- FFmpeg 合成后执行时长、分辨率、响度、字幕安全区、黑帧和重复画面检查。
- 预览页展示完整视频、文案、来源、素材许可和 AI 标识建议。

验收：缺少许可的素材无法进入合成；输出可重复生成；每个成片都有素材清单和成本明细。

## 阶段 4：多账号分发

- 优先使用平台官方发布 API；没有合规 API 的平台保留“辅助填充后人工确认”，不依赖绕过风控的模拟点击。
- 账号、栏目、标签、发布时间、日限额和内容模板分别配置。
- 发布任务使用幂等键，避免重试造成重复发布。
- 记录操作者、账号、稿件版本、发布时间、平台返回 ID、失败原因和撤回状态。
- 建立账号隔离、最小权限、令牌轮换、异常暂停和全局急停。

验收：测试账号完成端到端发布；重复提交不会产生第二篇；撤回、过期令牌和平台限流均可恢复。

## 推荐实施顺序

1. 先做阶段 2 的服务端任务、搜索适配器和证据层。
2. 再做纯图文发布包，验证选题质量和事实核验成本。
3. 然后完成单一 9:16 视频模板，再扩展多模板和供应商。
4. 最后接多账号分发；先测试账号和草稿箱，再逐个平台放量。

阶段 2 开始前需要确定三项配置：首个搜索服务商、首个模型服务商、首个发布平台。代码应始终通过适配器隔离供应商，避免业务流程绑定某一家 API。
