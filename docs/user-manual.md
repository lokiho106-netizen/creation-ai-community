# Pocket Studio 用户手册（开发测试版）

> 适用于只使用 Android 手机的用户。当前版本用于功能测试，尚未开放全自动发布。

## 1. 安装前准备

1. 在手机上安装今日头条 `15.4.0`（versionCode 15400）并登录自己的账号。
2. 建议在应用商店关闭今日头条自动更新，避免页面结构变化导致操作失败。
3. 只准备自己拥有权利或已经获得授权的视频和文章素材。

应用不需要清空相册，不需要准备占位视频，也不需要切换输入法。

## 2. 安装与无障碍

1. 在手机文件管理器中点 APK 安装；系统提示时允许“安装未知应用”。
2. 打开“Pocket Studio”。
3. 点“开启无障碍服务”。
4. 在系统列表中打开“Pocket Studio · 今日头条操作助手”。
5. 返回应用，确认“今日头条、无障碍、网络”状态。

无障碍配置只订阅今日头条包名，用于查找可见控件、点击、滚动和填写搜索词，不用于读取其他应用。

## 3. 资讯原创剪辑

1. 在“创作模式”选择“资讯原创剪辑”。
2. 填写主题和检索标签，例如“中美AI发展竞争”和“人工智能、芯片、大模型”。
3. 每行填写一个可信的 HTTPS RSS/Atom 地址，最多 10 个。只配置你允许访问、引用和发送给模型处理的信源。
4. 设置资讯回看时长和最多来源条数。
5. 按模型服务商文档填写聊天接口完整地址、API Key 和模型名称。
6. 点“检索并生成原创内容包”。应用会去重、按时效过滤、剔除与主题完全不匹配的条目，再生成图文稿、口播稿、封面提示词、分镜和标签。
7. 逐条打开来源核对日期、数字、引语和结论，再编辑或复制生成内容。

当前版本属于“可信信源聚合”，还不是通用搜索引擎。它不会抓取付费墙、绕过登录，也不会自动下载和搬用来源视频。生成内容会保存为应用内部的 JSON 内容包，界面会显示保存路径。

## 4. 授权视频筛选参数

- 关键词：搜索模式使用，多个词用逗号分隔。
- 标题标签/关键词：标题至少命中一个才进入候选。
- 排除词：标题命中后跳过。
- 最低播放量：只有固定版页面能稳定读取时才参与筛选；不能读取时不得拿点赞数代替。
- 最长发布时间：候选发布多久以内，单位小时。
- 最多翻页：一次找不到候选时允许的有限翻页次数。
- 每轮目标数：建议测试时设为 1。

只有切换到“授权素材快速处理”时，应用才显示这组配置和筛选按钮。

## 5. 模型接口与密钥

1. 在支持 OpenAI 兼容聊天接口的模型服务商处创建自己的 API Key。
2. 回到 Pocket Studio，填写服务商给出的 HTTPS 聊天接口完整地址、Key 和模型名称。
3. 默认配置指向 SiliconFlow；也可以换成 DeepSeek 等兼容接口。
4. 模型下线或名称调整时，按服务商的当前文档修改模型名称。
5. 输入原始标题，点“用模型生成新标题”测试。

Key 会由 Android Keystore 加密后保存在本机，并由手机直接请求用户填写的模型接口；项目不收集、不上传你的 Key。未填写 Key 时，标题工具只执行本地标点、空格和长度整理，原创内容包则不能生成。

免费模型有固定频率限制，达到限制时会显示稍后重试；“免费”不代表无限调用。

## 6. 解析、下载与按帧裁剪授权视频

1. 在今日头条打开有权使用的视频。
2. 点“分享”，选择“Pocket Studio”；也可以复制分享文本后手工粘贴链接。
3. 回到 Pocket Studio，勾选“我确认只处理自己拥有权利或已获授权的视频”。
4. 点“解析并下载到相册”。
5. 成功后视频位于相册的 `Movies/CreationAI` 目录。
6. 设置片头、片尾需要去掉的帧数，点“本地裁剪并导出新视频”。应用会优先读取视频真实帧率，读不到时按 30 fps 换算。

实现链路：

```text
今日头条分享链接
  → 跟随站内 HTTPS 跳转
  → 读取公开页面 RENDER_DATA
  → 解码 playAuthTokenV2
  → 请求字节跳动官方播放信息
  → 选择最高 720p MP4
  → 写入 Android MediaStore
```

应用拒绝非 HTTPS 页面、非支持域名和超过 512 MB 的媒体。下载失败会删除未完成的媒体条目。

## 7. 发布复核原则

当前测试版可以打开今日头条、选择最新媒体、填写标题并停在最终发布复核页。它不会替用户选择“自行拍摄”，也不会点击最终发布。用户必须确认：

- 视频画面、声音、字幕和标题无误；
- 没有捏造、夸大或误导性标题；
- 作品声明与真实来源一致；
- 今日头条与懂车帝的同步选项符合自己的意图；
- 账号和素材符合平台规则。

## 8. 常见问题

### 电脑检测不到手机

使用支持数据传输的数据线，在 USB 用途中选择“文件传输/Android Auto”，打开开发者选项和 USB 调试，并接受电脑指纹授权。

### 分享菜单没有 Pocket Studio

先启动一次 Pocket Studio；确认分享内容类型是文本链接。也可以复制链接后手工粘贴。

### 解析失败

确认链接来自今日头条或西瓜视频、网络可用、页面未删除。平台网页结构变化后需要更新解析器。

### 模型返回 400、401、429 或模型不存在

- 400：检查接口地址、模型名称以及服务商是否兼容 OpenAI Chat Completions；应用会对不支持 JSON 输出参数的接口自动降级重试一次。
- 401：检查 Key 是否完整、是否已失效。
- 429：达到免费模型频率限制，稍后重试。
- 模型不存在：去模型广场复制当前可用模型名称。

### 输入标题时键盘遮挡怎么办

应用优先使用 Android 无障碍的 `ACTION_SET_TEXT` 直接写入输入框，不需要切换输入法；失败时改用剪贴板粘贴；仍然失败才提示切换到系统输入法重试。这样不需要常驻专用输入法，也减少键盘遮挡。
